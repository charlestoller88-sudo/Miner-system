========================================
矿机管理系统 - 部署检查清单
========================================

【准备阶段】
☐ 已安装 Python 3.8+
☐ 已安装项目依赖（pip install -r requirements.txt）
☐ 确认网络可访问 10.102.0.0/24 和 10.102.1.0/24

【启动阶段】
☐ 双击运行 "启动系统.bat" 或执行 python app.py
☐ 终端显示: "Uvicorn running on http://0.0.0.0:8000"
☐ 没有报错信息

【Web 访问】
☐ 浏览器能打开 http://localhost:8000
☐ 首页正常显示（虽然矿机列表为空）
☐ 导航栏显示"仪表板"和"统计报表"

【矿机导入】
☐ 点击"IP扫描添加"按钮，弹出对话框
☐ 填写 IP 范围: 10.102.0.0/24,10.102.1.0/24
☐ 填写矿池过滤: poolbinance
☐ 点击"开始扫描"，显示"扫描中..."
☐ 等待 1-3 分钟，不要关闭窗口
☐ 显示"扫描完成！发现矿机: 92 台"
☐ 页面自动刷新

【验证导入】
☐ 首页顶部显示"矿机总数: 92"
☐ 矿机列表显示 92 行数据
☐ 每行显示矿机名称（如 NCATX.082）
☐ 显示 IP 地址（如 10.102.0.210）
☐ 显示矿机型号

【数据更新】（可选但推荐）
☐ 点击"扫描所有矿机"按钮
☐ 等待 2-5 分钟
☐ 刷新页面
☐ 矿机列表显示算力、温度、功耗数据

【功能测试】
☐ 点击任一矿机的"详情"按钮，能正常打开详情页
☐ 详情页显示矿机基本信息
☐ 详情页显示运行数据（可能需要等待扫描）
☐ 点击"统计报表"链接，能正常打开统计页面
☐ 统计页面显示矿机总数、在线数等数据
☐ 统计页面显示图表（饼图、柱状图）

【排序和搜索】
☐ 矿机列表顶部有排序下拉框
☐ 选择"算力↓高到低"，列表重新排序
☐ 选择"IP↑升序"，列表按 IP 排序
☐ 搜索框输入矿机名称，能过滤显示
☐ 搜索框输入 IP 地址，能过滤显示

【统计报表】
☐ 打开统计报表页面 http://localhost:8000/statistics
☐ 显示"矿机总览"卡片
☐ 显示"在线率统计"卡片
☐ 显示"理论算力"和"实际算力"卡片
☐ 显示矿机状态分布饼图
☐ 显示算力对比柱状图
☐ 点击"生成12小时报告"，能生成并显示报告

【终端日志检查】
☐ 终端显示 [IP扫描] 相关日志
☐ 终端显示 "发现矿机: 92 台"
☐ 没有 ERROR 或异常信息
☐ 访问页面时终端显示 HTTP 请求日志

【浏览器控制台检查】（按 F12）
☐ 打开浏览器开发者工具
☐ Console 标签没有红色错误信息
☐ Network 标签显示 API 请求成功（状态码 200）
☐ 统计页面日志显示 [统计页面] 数据加载成功

========================================
部署成功标准
========================================

✅ 所有检查项都打勾
✅ 能看到 92 台矿机列表
✅ 能查看矿机详情
✅ 统计报表正常显示
✅ 没有错误提示

如果某项未通过，请查看:
1. 终端日志（运行 python app.py 的窗口）
2. 浏览器控制台（F12 → Console）
3. 部署指南.md 的"常见问题"部分

========================================
后续操作建议
========================================

1. 让系统运行 10 分钟，等待自动扫描更新数据
2. 刷新页面查看最新的算力、温度数据
3. 定期查看统计报表，监控矿机运行状况
4. 处理告警信息（如有）
5. 每周生成一次 12 小时运行报告
